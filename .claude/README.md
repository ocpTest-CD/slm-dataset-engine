# slm-dataset-engine Claude 上下文

这个目录保存 AI 在 `slm-dataset-engine` 中协作时需要按需读取的长期上下文。项目级规则以 `../AGENTS.md` 为准。

## 默认任务理解

- 当前项目是小模型数据集流程工作台。
- 产品目标是把数据集接入、清洗、生成、审核、质检、版本、导出和评测闭环流程化。
- 技术方向是 React + Vite 前端、Go 后端控制面、Python 数据处理与模型 Worker。
- 项目不追求一开始做复杂可视化编排器，优先做稳定的数据集版本和质量闭环。

## 阅读原则

- `.claude/` 是按需阅读目录，不要求每次全量读取。
- 任务涉及哪个技术栈，就读取对应规范。
- 任务跨越前端、后端、Worker 或数据库时，必须读取架构文档和技术规范。
- 若上下文不足，先检查本目录是否已有相关说明，再查看代码和配置。
